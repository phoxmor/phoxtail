The menu, media and collection pickers now require an operator. They asked for `phoxtail_agent.access_chatbot` — the same permission as the chatbot itself — while returning every image, document and collection in the project unnarrowed, so anyone granted chat access could read the whole library by requesting the URL. Pages were already narrowed to what the Wagtail explorer would show and are unaffected. The two buttons that open the picker follow the same rule; the one inside the chat composer previously had no check at all.
