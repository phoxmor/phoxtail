The MCP server's `401` now points at its protected-resource metadata (RFC 9728), and that document names the site as the authorization server — a remote client can find where to authenticate from the MCP URL alone. The MCP server's public address is `mcp.` in front of the site's: `mcp.<slug>.localhost` locally, `mcp.<DOMAIN>` in production, with nothing new to configure. Exposing that address in production — DNS, certificate, nginx — is separate and not yet done.
