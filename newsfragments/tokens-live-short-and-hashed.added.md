The authorization server's tokens now live an hour (access) and a week (refresh, renewed on every use), are stored hashed rather than in cleartext, and a replayed refresh token revokes everything descended from its grant. No grace window for a retried refresh: the library's grace path returns the previous token's stored value, which hashing leaves blank, and errors — hashing wins, and the retry ends in a login. `manage.py sweeptokens` removes dead token rows of both families — the authorization server's and phoxtail's own, including every revoked chat-turn credential — after 90 days (`--retention-days`); nothing schedules it yet.
