A key issued for the MCP server — a client names it with `resource=` when asking, and the authorization server records it — is now honoured at the API, which stands behind that server rather than being it. The library's own check compared the request's address with the key's and refused every such key; phoxtail's asks whether the key names this project's MCP server, comparing both spellings canonically (lowercase, no default port, no trailing slash), so a key for another host or for the site's own origin is refused and a key for the door opens the doors behind it. The MCP path is one constant, `MCP_PATH`, shared by the server and the resource name. `E005` fails startup if a project's settings displace the check.
