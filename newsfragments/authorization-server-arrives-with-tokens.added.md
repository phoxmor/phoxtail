The site is now an OAuth 2.1 authorization server (django-oauth-toolkit, in the `engine` extra), declared as a surface of `phoxtail.tokens`: the RFC 8414 discovery document at `/.well-known/oauth-authorization-server` and the endpoints under `/o/`. A hatched project picks it up on upgrade with nothing edited — the dependency, the URL mount and the `OAUTH2_PROVIDER` defaults all arrive through the app protocol, and `migrate` runs on every start as it already does. Its `issuer` is published as the exact name the MCP server advertises; the implicit grant, the password grant and plain PKCE challenges are refused from the first day; and a system check fails startup if a project's own `OAUTH2_PROVIDER` displaces either. Nothing else is switched on: no registration, no scopes of phoxtail's own.
