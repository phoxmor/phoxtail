A local (stdio) MCP session is now offered only the tools its stored credential covers, as a remote one already was. Sessions tools are unaffected — they are limited by the transport, not by a credential — and with no stored token, or while the API cannot be reached, the whole surface is offered as before. Note what a smaller catalogue costs: a tool that is out of a token's reach is now absent rather than refused, so the message naming the permission that would have allowed it no longer appears.
