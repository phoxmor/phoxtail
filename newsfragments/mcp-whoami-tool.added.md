`phoxtail_whoami` reports who a local session is acting as, what its stored token permits, and which tools were withheld from the tool list because of it — with the permission each one would have needed. It answers the question a filtered catalogue can no longer answer by itself: a tool that is out of a token's reach is absent rather than refused, and an absent tool names nothing. Local sessions only, since over HTTP a list of withheld tools describes the surface to a caller who was not shown it.
