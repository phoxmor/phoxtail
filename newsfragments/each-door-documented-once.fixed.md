The OpenAPI schema at `/api/docs` now lists the API's two ways in — a Bearer token and a session cookie — once each, and every endpoint names both. Before, every endpoint using `guarded()`, `scoped()` or `authenticated()` pointed at a single scheme called `Authorize`, which described either the cookie or the header depending on which apps were installed, so Swagger's "Try it out" and generated clients sent the wrong credential or none.
