A client the site has never met can now introduce itself to the authorization server, two ways and granting nothing either way: by document — its `client_id` is an `https` URL the site fetches through the library's SSRF-hardened fetcher, from any host, and the consent screen names that host — or by request, anonymously, at `/o/register/` (RFC 7591, with RFC 7592 read-back). Both create a public client that still sends every person to the consent screen; neither can mark itself as needing no consent. The discovery document advertises both. An operator who wants only listed hosts to register by document sets the library's allowlist class and hosts in the project's settings. `E006` fails startup if a project's settings close either door.
