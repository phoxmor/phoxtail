A client that identifies by document and publishes grant types beyond the ones this server offers — one document for every server it talks to — was refused as an unknown client, because the library's resolver demands exactly one grant type besides refresh. The document is now fetched by the library's own hardened fetcher and narrowed to the grants this server offers before the library judges it, as RFC 7591 allows a server to do; a document naming only grants this server lacks is still refused in the library's words. Found on the first connection from a hosted client.
