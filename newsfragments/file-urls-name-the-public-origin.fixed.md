File URLs the API hands out — images, documents, videos, audio and their thumbnails, and font files — are built on `WAGTAILADMIN_BASE_URL`, the origin the project is configured to be known by, instead of the hostname the caller happened to use. The MCP server reaches the API as `http://web` inside the compose network, so every `file_url` it relayed to a remote connector pointed at that container. `phoxtail net attach` now writes `DOMAIN=<slug>.localhost` (the setting that origin is derived from) and `detach` takes it back; a project already attached needs the line added to `.env` by hand or a fresh `attach`, then `web` restarted.
