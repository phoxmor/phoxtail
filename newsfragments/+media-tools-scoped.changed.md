The twenty-one media MCP tools name the codename their endpoint names, so a
token scoped to less than an act is not offered the tool that performs it. The
codenames are Wagtail's own — `wagtailimages.*`, `wagtaildocs.*`,
`wagtailmedia.*` — because each permission policy pins itself to Wagtail's model
even where the project swaps in its own. Reading video and audio names
`change_media`: wagtailmedia has no `choose` permission, so a credential
narrowed to listing them is spelled the same as one that may edit them.
