`phoxtail install <package>` no longer fails its pre-flight check for every package on PyPI. It asked `uv pip index versions`, a subcommand no longer present as of uv 0.11, and read the resulting error as "not found on PyPI"; the check now queries PyPI's JSON API directly. An unreachable index no longer blocks the install either — a package is reported missing only when PyPI says it is.
