The phoxtail bar now appears for anyone who can use something in it, rather than for superusers only. Granting `phoxtail_agent.access_chatbot` from the Wagtail admin previously did nothing visible: the bar's own per-item permission checks sat inside a blanket superuser check that answered first, so the permission was grantable and opened nothing. Each item now asks its own question — a person holding only chat access sees the chat button and not the media picker, the page controls or the admin links.
