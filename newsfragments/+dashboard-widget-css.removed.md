The old dashboard widget styles are gone: `.dash-widgets-grid`, `.dash-widget-card`, `.dash-widget-title`, `.dash-widget-link`, `.dash-widget-header`, `.dash-widget-list*`, `.dash-widget-cta` and `.dash-widget-empty*`. Widget cards no longer carry a statistic or a detail line either, so `.dash-widget__stat` and `.dash-widget__meta` and the `stat`/`meta` context keys behind them are gone with them. A site whose own widget templates use these class names must restyle them.
