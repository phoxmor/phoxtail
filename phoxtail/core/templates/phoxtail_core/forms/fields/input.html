{% comment %} MD3 outlined text field for every box the form's widget draws — text, numbers, dates, date-times: the widget decides the type (see select.html for the anatomy notes). A date or date-time box never matches :placeholder-shown, so its label is permanently floated; the browser's picker indicator is hidden in CSS and the trailing calendar button opens the picker instead. A password box gets the show/hide button (js/fields.js); like Django, it never writes the typed value back. Django's own widget draws the control, so it carries what the form declares: the value formatted for the active language, type, required, disabled, maxlength, autocomplete, and the aria-describedby link to the line under it (Django's ids: _helptext, _error). The label rests inside the container and floats into the outline notch on focus/populate, driven by :placeholder-shown — hence the single-space placeholder fallback. A caller-supplied placeholder is kept but only becomes visible on focus (CSS hides it while the label rests in its place, per MD3). input_type overrides the widget's type. Any hx_* option reaches the control; the htmx settings are written only when it makes a request (hx_get, hx_post, hx_put, hx_patch, hx_delete). {% endcomment %} {% load i18n phoxtail_core_tags phoxtail_design_tags %}
