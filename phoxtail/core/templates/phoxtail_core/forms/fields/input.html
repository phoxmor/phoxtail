{% comment %} MD3 outlined text field, for text and numbers alike: the form's widget decides the box type (see select.html for the anatomy notes). Django's own widget draws the control, so it carries what the form declares: the value formatted for the active language, type, required, disabled, maxlength, autocomplete, and the aria-describedby link to the line under it (Django's ids: _helptext, _error). The label rests inside the container and floats into the outline notch on focus/populate, driven by :placeholder-shown — hence the single-space placeholder fallback. A caller-supplied placeholder is kept but only becomes visible on focus (CSS hides it while the label rests in its place, per MD3). input_type overrides the widget's type. Any hx_* option reaches the control; the htmx settings are written only when it makes a request (hx_get, hx_post, hx_put, hx_patch, hx_delete). {% endcomment %} {% load phoxtail_core_tags %}
