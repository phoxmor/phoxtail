{% comment %} MD3 choice group: a body-small group label above a grid of option rows (checkboxes: 18dp rounded squares; radios: 20dp ring-and-dot — list-item style, no pill containers). The form's widget decides which: RadioSelect draws radios, CheckboxSelectMultiple checkboxes. Django draws each option through its own widget, pointed at choices/options.html and choices/option.html, so values, ticks, ids, groups, disabled and every hx_* option reach each input. grid_modifier adds grid classes, e.g. phx-choices--7col (the weekday picker, whose form gives short names).
