{% load i18n %} {% comment %} Single Select Search Widget (MD3 outlined field + menu panel) ============================================================= A searchable single-select. The trigger is an MD3 outlined field whose label rests inside and floats into the outline notch when the panel opens or a selection exists. The label/outline live HERE, outside the HTMX swap target, because the search endpoint re-renders input.html without the label/show_label context; float state is driven purely by CSS :has() (a hidden input exists only while something is selected), so it survives swaps.
