{% comment %} Segmented control: one segment per choice of the form field, a sliding thumb under the chosen one (styled in widgets.css, up to five segments). Sized to the shared MD3 field height (56dp) so it can sit in a form row next to outlined fields. The form's RadioSelect draws each radio through segmented_control/options.html and segmented_control/option.html, so values, the checked segment, ids, disabled and every hx_* option reach each input; the chosen radio submits its own value. A disabled form field greys the whole control. Help text and errors render as MD3 supporting text. {% endcomment %} {% load phoxtail_core_tags %}
