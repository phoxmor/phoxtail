{% comment %} Date stepper for a page that shows one day or week at a time: one pill holding the date between two arrows that step it back and forward (previous and next: the neighbouring values). text, when given, is shown in place of the date, e.g. the week it falls in; the date shows while the keyboard is in the box. period is what one step moves, "day" (the default) or "week": a week's text changes width as it steps, so its pill keeps room for the longest. Looks: filled + small (a pill, for toolbars); no other look exists yet. Django's own widget draws the box, always a date box. A click anywhere on the date opens the browser's picker. The box sends the field's request on its "step" event (js/fields.js): an arrow or a picked day sends at once, a typed date on Enter or when the box is left, so a half-typed date is never sent. Any hx_* option reaches the box; a caller's trigger is followed by "step", which the arrows and the picker need. The htmx settings are written only when it makes a request (hx_get, hx_post, hx_put, hx_patch, hx_delete). The arrows carry ids from the field's, so a redraw gives the focus back to the one that had it. {% endcomment %} {% load i18n phoxtail_core_tags phoxtail_design_tags %} {% with period=period|default:"day" %}
