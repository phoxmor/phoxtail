{% comment %} Search bar for a list's filters: one pill holding a magnifier (a clear button once there is text), the box and, when count is given, the number of results. Looks: filled + small (a pill, for toolbars); no other look exists yet. Django's own widget draws the box. Typing sends the field's request half a second after the last key; Enter and the clear button send it at once (js/fields.js), through the box's "search" trigger, which is kept whatever trigger the caller sets. The answer is expected to redraw the list out of band, so the box itself swaps nothing (hx_swap "none"). Any hx_* option reaches the box and overrides these defaults; the htmx settings are written only when it makes a request (hx_get, hx_post, hx_put, hx_patch, hx_delete). {% endcomment %} {% load i18n phoxtail_core_tags phoxtail_design_tags %}
