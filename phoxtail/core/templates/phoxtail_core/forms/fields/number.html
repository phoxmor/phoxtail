{% comment %} MD3 outlined text field, number variant (see select.html for the anatomy notes). Django's own widget draws the control, so it carries what the form declares (min, max, step, required...) and writes the value the way a number input reads it, whatever the language. Unlike the select, this field can be empty, so the label rests inside the container and floats into the outline notch on focus/populate — driven purely by :placeholder-shown in CSS, which is why the input always carries a single-space placeholder. Any hx_* option reaches the control; the htmx settings are written only when it makes a request (hx_get, hx_post, hx_put, hx_patch, hx_delete). {% endcomment %} {% load phoxtail_core_tags %}
